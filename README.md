# ARIVA

Адаптивный сайт компании ARIVA: автомобили из Китая в Беларусь.

В подборке 24 автомобиля: 8 ДВС, 8 электромобилей и 8 гибридов. Есть страницы автомобилей с галереями, этапы работы, FAQ, калькулятор растаможки и политика конфиденциальности.

Статический HTML/CSS/JavaScript. Для GitHub Pages: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll.

Формы обратной связи пока работают в режиме демонстрации; отправка заявок не подключена.
